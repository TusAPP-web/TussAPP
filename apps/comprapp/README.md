# ComprAPP
Aplicación PWA de economía familiar, listas de compras y comparación de precios, integrada a TusAPP.

## Ubicación
- Repositorio: TusAPP-web/TussAPP.
- Carpeta exclusiva: apps/comprapp/.
- URL prevista: https://tusapp-web.github.io/TussAPP/apps/comprapp/

## Aislamiento
ComprAPP mantiene sus propios HTML, CSS, JavaScript, manifest y service worker. No comparte archivos internos ni modifica apps/gimapp, apps/turnapp ni otras aplicaciones.

## Estado
Estructura inicial publicada en el repositorio. No incluye todavía Firebase, autenticación, catálogo real, comercios, pagos ni sincronización de datos.
